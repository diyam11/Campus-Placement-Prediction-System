# Campus Placement Prediction System

A machine learning project that explores student placement prediction using academic performance and other relevant student attributes.

## 📌 Project Overview

The Campus Placement Prediction System aims to estimate whether a student is likely to be placed based on selected academic and employability-related features.

The project was developed using Python and Jupyter Notebook as a practical application of data analysis and machine learning.

## 🎯 Objectives

- Explore student placement-related data
- Understand the relationship between student attributes and placement outcomes
- Prepare data for machine learning
- Train and evaluate a placement prediction model
- Explore how predictive analytics can support placement-related decisions

## ✨ Features

- Dataset-based analysis
- Data preprocessing and preparation
- Machine learning model development
- Placement prediction based on input features
- Analysis of model predictions

## 🚀 Getting Started

### Prerequisites

- Python 3
- Anaconda or Jupyter Notebook
- The Python libraries used in the notebook

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/diyam11/Campus-Placement-Prediction-System.git
   ```

2. Open the project folder:

   ```bash
   cd Campus-Placement-Prediction-System
   ```

3. Install the dependencies listed in `requirements.txt`, if available:

   ```bash
   pip install -r requirements.txt
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the project notebook and run the cells in order.

6. Ensure the dataset is available at the file path referenced in the notebook.
